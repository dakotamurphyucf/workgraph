The application owns one `ProtocolProcessor`, shared through `HttpClient.processing` and the operation controller. Its dedicated worker performs lossless JSON parsing/encoding/canonicalization, full operation validation, identity hashing and pinned provider projection. There is no main-thread production fallback. Expected aborted/busy/deadline/protocol failures are values; unexpected worker exceptions reject. Disposal and active cancellation terminate the worker, while queued cancellation leaves another active job alone. None of these actions retries or stops a daemon write.

Admission captures closed metadata before yielding. Decoder-owned JSON and public immutable builders carry ownership certificates; certificates never skip domain validation. Small mutable caller trees are copied with fixed bounds. Large mutable trees must first use `processing.parse`. Publication rechecks the latest intention identity/revision after asynchronous validation. Preparation/request/receipt fingerprints are SHA-256 over domain-separated canonical UTF-8 and include canonical byte length; native saved request/hash/receipt fields remain unchanged.

Public ordinary requests retain 4 MiB / 96-depth/100,000-node limits. Expanded operation inspections retain 16 MiB / 96-depth/400,000-node limits. Up to 64 pending jobs and 32 MiB logical input reservations bound admission; reservations use actual source bytes or conservative certified-tree size estimates capped at the job budget. Worker deadlines are 30 seconds including queue time. Busy is explicit; callers must not silently retry writes.

The private data transport uses 32 KiB, at most1,024-record packets with acknowledgement backpressure, transferred owned buffers and a closed set of data tags. It preserves numeric lexemes, source UTF-16 code units for semantic Unicode validation, scalar pairs at splits, own prototype-like field names and exact source bytes. It rejects cycles/accessors, duplicate identities, invalid references and aggregate budget violations. Its 512-level representation limit covers public 96-container ASTs plus field records/arrays/DTO envelopes. Incremental ownership/size reconstruction avoids a second full validation walk or full AST structured clone on the main thread. Full domain validation remains worker-owned.

Pure worker algorithm tests use an explicitly injected loopback port in `tests/core/processing-harness.ts`, including structuredClone transfer/detachment. Browser qualification uses the actual dedicated Worker over native companion/daemon fixtures, explicit synthetic full-size response data, ordinary native reads and a large schema-valid durable unsent preparation. Test-only assets/endpoints are never installed. Keep native browser requests outside Playwright routing interception when measuring their completion; failed intercepted traces are retained as test-harness evidence rather than suppressed.
