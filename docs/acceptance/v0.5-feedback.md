context policy and external side effects. It adds no model runtime, MCP server,
authentication boundary or distributed scheduler.

Review caught project-filtering gaps in the actor overview and milestone-linked
Attention routing. The corrections share current membership for overview requests
and notifications, and use event-bound membership for captured Attention pages.
Two daemon regressions check pagination, negative cross-project cases, moves,
restart and preservation of the raw inbox audit. Review also corrected missing
hierarchy and amendment digest record codecs; large records require a sufficient
budget and retain their complete validated contents.

Final integration checks also corrected reservation wait classification when a
read exhausts the total deadline, preserved the detailed direct dependency-cycle
path before checking inherited edges, and updated export fixtures to the current
format. The pipe-output regression now uses one schema response through the same
output path, so catalog construction cannot consume its timeout; its quiet exit
assertions are unchanged. PTY fixtures establish their own foreground process
group, restore terminal state and handle Linux EOF explicitly.

## Combined workflow

A fresh candidate daemon passed a 51-call scenario spanning the feature families:

1. An inherited prerequisite and an allowed-actor rule gate worker acquisition.
2. The worker starts an attempt and receives an instruction requiring acknowledgement.
   Premature completion rejects.
3. A project-scoped overview discovers the worker's question. Delivery
   acknowledgement, responsibility acceptance and answer resolution happen explicitly.
4. Preflight leaves the planning head unchanged. After acknowledging the instruction,
   one transaction stores a result fact and finishes the ticket with an evidence link.
5. Fact predicates, reverse references and named reported usage remain discoverable.
6. The local canceled-child policy permits parent completion. Project completion
   records the handoff. Restart preserves result bytes, answer, usage and handoff;
   retrying the committed result transaction returns its exact original receipt.

The implementation workspace retains the source and result as
`root-combined-workflow-source` and `root-combined-workflow-result`. The candidate
daemon used disposable roots, never the installed 0.4 development tracker.

The second reviewer ran a complementary daemon scenario with an inherited
dependency, pool, automatic path hold and required amendment. A late source
reopening in a completion transaction rejected the entire batch, preserving the
claim, attempt, acknowledgement, path holder and planning revision. Valid completion
released the path once; old acquisition and completion receipts survived restart
and export/verify/restore. Its source and result are retained as
`final-review-cross-family-source` and `final-review-cross-family-result`.
