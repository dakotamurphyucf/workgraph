# v0.4 client usability review

This record covers the [accepted preview contract](../preview-0.4-contracts.md).
The release keeps the existing local service and storage architecture. Storage
compaction, allocation redesign and additional platforms remain deferred.

## Review and regression coverage

The primary agent reviewed all changed production paths, public interfaces,
tests and guides. A second reviewer also checked the completion receipts and
protocol/service failure boundaries. Review caught an unbounded numeric request
ID in error responses; numeric IDs now have a 256-byte encoded limit, with a
regression for a 1.5MB finite numeric input.

## Integrated user workflow

A separate CLI walkthrough passed against the candidate `0.4.0` executable:

1. Start a private daemon; create a workspace, project and ticket.
2. Actor Alice starts the ticket and asks a ticket-linked question with Bob as
   recipient and designated resolver, using an agent-local context and journal.
3. Bob uses `request get` and ticket/resolver-filtered `request list`, then answers
   and resolves in one saved mutation.
4. Retrying that exact answer returns the identical result. The thread contains
   exactly the question and answer.
5. Alice finishes the task; returned `ticket_revision` equals the revision from
   the `ticket get` alias.
6. Restart the daemon and retry the saved answer again; its original result survives.

The implementation tracker retains the walkthrough source as resource
`ux05-integrated-check`; local tracker data and request files are not release source.
