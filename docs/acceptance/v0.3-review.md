## Whole-tree checks

Executed on the development macOS ARM64 host using the repository's pinned switch:

```sh
./dev fmt
./dev build @fmt @runtest @install
python3 tools/generate_api_reference.py --binary _build/default/bin/main.exe \
  --output docs/api-reference --check
python3 tools/check_agent_guide.py . --binary _build/default/bin/main.exe
```

The whole-tree gate passed, including all 68 top-level integration cases and the
focused expect/socket suites. The final schema review also tightened initialize's
registry format field to the literal current identifier; generated references and
the whole-tree gate passed again after that change.

The first whole-tree run exposed two stale assertions expecting `Conflict` for an
existing local download destination. The accepted local-file contract uses
`Invalid_argument`, including exclusive-publication races. Review confirmed that
the tests still verify preserved destination bytes and temporary-file cleanup;
the expectations and guide were updated. No changed expectation was used to accept
a corruption or unexpected exception.

Primary review also found that prefixing copied handoff evidence could exceed its
65,536-byte limit during rollover. The recipe now preserves the exact evidence and
puts the historical/no-successor-approval label in its explicit mapping. A full-size
UTF-8 evidence fixture verifies first execution and exact rerun.
