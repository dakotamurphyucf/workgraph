# Team workflow checkpoints

The [README](../../README.md) contains the complete tutorial, eight use cases,
prompts, diagrams and maintained script sources. Agents should start with the
short [capability guide](../../AGENT_GUIDE.md), then load one focused reference.

Before work, obtain an executable, private context/request directory, workspace,
actor, optional registered run, assigned ticket and exact path scopes. Read its
latest handoff, amendments, acceptance policy and relevant inbox. Parenthood
does not inherit dependencies unless explicitly configured.

While working, keep small named results in facts, reasons in decision comments,
long material in resources, and accountable questions in requests. Save exact
write requests before transmission. Persist meaningful recovery notes before
compaction; model context policy and process supervision belong in the harness.

After a known empty `claim_next`, inspect run-aware eligibility and use a
filtered attention wait. Empty standalone allocation is nondurable, but repeatedly
calling it still wastes calls. Capture before checking and parking; retain exact
cursors and all continuation/omission flags. Never refresh stale guards silently.

Before finish, check actual tests, evidence versions, review/validation policy,
required instruction acknowledgements and child/prerequisite conditions. Publish
external captures first, then atomically record result pins/facts and finish.
Publication plus resource linking are separate receipts, not one atomic write.

Automatic required path holds track exact claim borrowers and release when the
last borrower leaves. Manual holds survive and require exact owned fence release.
Expiration and terminal lifecycle status do not authorize foreign cleanup or
establish that the harness process stopped. Recovery is a separate audited action
after the harness verifies stopped/isolated state.

Before sharing, review visible transcript/tool data and captured outputs for
secrets, export a consistent snapshot, verify it, restore into a fresh private
root and trace decisions to immutable sources. Private model reasoning is never
input to the transcript converter. Independent writers' histories do not merge.
