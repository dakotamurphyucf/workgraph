# session

Generated from `workgraph discover --catalog`. Do not edit this file.

Sessions group conversation and tool events explicitly imported by a harness.

**Use when:** A runner needs a retained transcript container and event append lifecycle.

**Choose carefully:** A session stores imported events; it does not run a model or automatically collect private reasoning.

**Start with:** [session.list](../api/session.list.md), [session.create](../api/session.create.md), [session.append](../api/session.append.md).
