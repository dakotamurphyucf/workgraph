# reconciliation

Generated from `workgraph discover --catalog`. Do not edit this file.

Reconciliation records how work handles an explicitly changed pinned input.

**Use when:** A changed-input record requires an attributed decision about reuse or replacement.

**Choose carefully:** Reconciliation makes handling explicit; it does not rewrite old evidence or rerun a process.

**Start with:** [reconciliation.list](../api/reconciliation.list.md), [reconciliation.record](../api/reconciliation.record.md).
