# workflow.verify_outputs

Generated from `workgraph discover --catalog`. Do not edit this file.

Publish exact output evidence, obtain formal checks and review, then accept and finish the current generation.

**Use when:** Completed work must satisfy reproducible validation and independent review requirements.

`workgraph help workflow.verify_outputs` · [Focused reference](../gated-review-workflow.md)

1. Read the effective acceptance policy and review requirements before running checks; retain the observed policy digest and current claim and attempt binding.
2. Run the actual command through the harness, optionally using local evidence-run; inspect its observed outcome, truncation and declared source coverage before publishing with evidence-publish.
3. Publish the contract and manifest with exact resource versions and digests; retain the returned manifest revision, then submit it through review.submit as a new generation.
4. Record validation.add against the exact manifest and observed policy digest. A distinct configured reviewer inspects those exact outputs and records review.record for the actual generation.
5. Inspect review.gate; an approve message alone does not establish acceptance. Resolve changes requests explicitly, resubmit changed outputs as a new generation, and obtain fresh proof.
6. For each required acceptance criterion, perform the stated check and record acceptance.assert with its current effective policy digest, exact evidence pins and actual ownership guards. Validation and reviewer verdicts do not replace these assertions.
7. When the current generation passes review.gate, save review.accept under the observed submission revision. Inspect ticket.readiness for all remaining completion requirements, then ticket.finish under actual ownership.
