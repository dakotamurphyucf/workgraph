# history

Generated from `workgraph discover --catalog`. Do not edit this file.

History stores explicitly imported conversation and tool events with exact payload retrieval.

**Use when:** You need to traverse a session, search imported events or retrieve a retained payload.

**Choose carefully:** History is separate from planning activity; Workgraph does not capture model conversations automatically.

**Start with:** [history.read](../api/history.read.md), [history.payloads](../api/history.payloads.md), [history.payload](../api/history.payload.md).
