# dependency

Generated from `workgraph discover --catalog`. Do not edit this file.

Dependencies make one ticket require another and record explicit waivers.

**Use when:** Work must wait for a prerequisite, or a justified waiver should lift that block.

**Choose carefully:** A dependency controls readiness; parenthood and related links have different semantics.

**Start with:** [dependency.add](../api/dependency.add.md), [dependency.waive](../api/dependency.waive.md), [dependency.remove](../api/dependency.remove.md).
