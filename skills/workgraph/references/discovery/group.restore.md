# restore

Generated from `workgraph discover --catalog`. Do not edit this file.

Restore cancellation withdraws a pending uninstalled restore intent explicitly.

**Use when:** A pending restore should release reservations before any target is installed or occupied.

**Choose carefully:** Cancellation never rolls back a published target; partial publication requires the original restore retry.

**Start with:** [restore.cancel](../api/restore.cancel.md).
