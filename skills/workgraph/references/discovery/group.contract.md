# contract

Generated from `workgraph discover --catalog`. Do not edit this file.

Contracts declare versioned input and output expectations for evidence.

**Use when:** An attempt's outputs must conform to a named schema or pinned expectation.

**Choose carefully:** A contract defines requirements; a manifest names the exact produced and consumed evidence.

**Start with:** [contract.list](../api/contract.list.md), [contract.get](../api/contract.get.md), [contract.put](../api/contract.put.md).
