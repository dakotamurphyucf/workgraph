# message

Generated from `workgraph discover --catalog`. Do not edit this file.

Messages send informal immutable-body communication to frozen recipients.

**Use when:** A participant needs to send an attributed note to actors, runs or teams.

**Choose carefully:** Messages notify; accountable questions belong in requests and formal verdicts in reviews.
