# project

Generated from `workgraph discover --catalog`. Do not edit this file.

Projects group delivery goals, tickets, milestones and completion policy.

**Use when:** You need to organize a goal, inspect its brief or check and finish the whole project.

**Choose carefully:** Project completion checks its work and gates; a project brief is only a captured summary.

**Start with:** [project.list](../api/project.list.md), [project.brief](../api/project.brief.md), [project.readiness](../api/project.readiness.md), [project.create](../api/project.create.md).
