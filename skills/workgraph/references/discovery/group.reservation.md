# reservation

Generated from `workgraph discover --catalog`. Do not edit this file.

Reservations coordinate named resources or lexical file scopes with fencing tokens.

**Use when:** Cooperating runs need shared or exclusive access, renewal, release or guarded recovery.

**Choose carefully:** These are logical grants, not filesystem locks; expiry does not free holders or stop processes.

**Start with:** [reservation.contention](../api/reservation.contention.md), [reservation.acquire](../api/reservation.acquire.md), [reservation.paths.acquire](../api/reservation.paths.acquire.md).
