# validation

Generated from `workgraph discover --catalog`. Do not edit this file.

Validations record attributed check outcomes against exact evidence.

**Use when:** A gate requires a named validator's recorded result for a pinned manifest or resource.

**Choose carefully:** The record reports a caller's check; Workgraph does not execute or independently verify the check.

**Start with:** [validation.list](../api/validation.list.md), [validation.add](../api/validation.add.md).
