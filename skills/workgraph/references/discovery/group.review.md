# review

Generated from `workgraph discover --catalog`. Do not edit this file.

Reviews freeze submitted evidence generations and record independent verdicts and acceptance.

**Use when:** Outputs need configured reviewers, validation gates and explicit acceptance before completion.

**Choose carefully:** One approve verdict is not acceptance; review.accept checks the full current generation's gate.

**Start with:** [review.gate](../api/review.gate.md), [review.submit](../api/review.submit.md), [review.record](../api/review.record.md), [review.accept](../api/review.accept.md).
