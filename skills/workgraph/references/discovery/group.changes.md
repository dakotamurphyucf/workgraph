# changes

Generated from `workgraph discover --catalog`. Do not edit this file.

Change feeds expose complete captured commit metadata with resumable cursors.

**Use when:** A consumer needs to follow planning or history commits and wake on matching changes.

**Choose carefully:** Changes carry commit metadata; activity and history methods expand the underlying content.

**Start with:** [changes.read](../api/changes.read.md), [changes.wait](../api/changes.wait.md).
