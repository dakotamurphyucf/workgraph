# comment

Generated from `workgraph discover --catalog`. Do not edit this file.

Comments retain attributed text revisions on planning subjects.

**Use when:** You need to add discussion, inspect exact prior text or explicitly tombstone a comment.

**Choose carefully:** Comments are editable retained discussion; request resolution and formal review use their own records.
