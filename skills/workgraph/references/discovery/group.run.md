# run

Generated from `workgraph discover --catalog`. Do not edit this file.

Runs record attributed agent invocations, reported lifecycle, budgets and observations.

**Use when:** A harness needs to register an invocation and coordinate its work and usage.

**Choose carefully:** Run status and heartbeat are caller-reported metadata; they never launch, stop or prove liveness of processes.

**Start with:** [run.register](../api/run.register.md), [run.get](../api/run.get.md), [run.observe](../api/run.observe.md).
