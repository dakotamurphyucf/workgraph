# workflow.backup_restore

Generated from `workgraph discover --catalog`. Do not edit this file.

Create an immutable portable backup and restore it into a fresh root with explicit lifecycle checks.

**Use when:** A local workspace must be backed up, transferred or recovered through its supported portable format.

`workgraph help workflow.backup_restore` · [Focused reference](../administration.md)

1. Read daemon.health and workspace.list; choose a fresh absolute export destination outside managed roots with an existing parent.
2. Save workspace.export and retain the actual export job ID and captured heads; writes may continue while that immutable capture materializes.
3. Poll export.get until a terminal status and use export.verify on the published complete workspace export; admission is not proof of completed publication.
4. Save workspace.restore for a fresh private root in a registry where the exported workspace identity is absent. Preserve the old data while verification and replay run.
5. Inspect the durable restore receipt, then explicitly workspace.open because restore registers the new root closed. Read workspace.overview and exact retained sources before new work.
6. For a direct portable-tree handoff instead, finish exports and workspace.close before the harness copies or transfers it; maintain one writer at a time and verify ancestry on register/open.
