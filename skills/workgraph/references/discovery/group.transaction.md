# transaction

Generated from `workgraph discover --catalog`. Do not edit this file.

Transactions prepare and atomically publish bounded ordered planning operations.

**Use when:** Several planning changes must either all commit or all fail, including newly created entity aliases.

**Choose carefully:** Preflight validates without reserving state; only apply commits and returns a durable receipt.

**Start with:** [transaction.preflight](../api/transaction.preflight.md), [transaction.apply](../api/transaction.apply.md).
