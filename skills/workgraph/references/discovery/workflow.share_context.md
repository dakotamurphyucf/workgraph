# workflow.share_context

Generated from `workgraph discover --catalog`. Do not edit this file.

Choose bounded facts or versioned resources and carry exact evidence pins into later work.

**Use when:** Agents need to share structured context, longer notes or binary artifacts durably.

`workgraph help workflow.share_context` · [Focused reference](../resources.md)

1. Use fact.keys or resource.list to discover existing context before creating a duplicate record; expand only selected values or metadata.
2. For small JSON values read fact.get and use its actual fact revision with fact.put; JSON null is a value rather than deletion.
3. For small UTF-8 text use resource.put_text with the resource metadata guard, or the local resource.publish_text helper when a new ticket link must publish atomically.
4. For large or binary bytes use the local resource.upload saved plan; ticket linking in that helper is separate and can require exact recovery.
5. Retain the returned immutable content version and digest independently of metadata revision; retrieve exact content through resource.read, resource.read_text or verified resource.download.
