# usage

Generated from `workgraph discover --catalog`. Do not edit this file.

Usage records store immutable caller-reported consumption and named integer samples.

**Use when:** A harness must report and aggregate observed usage for bookkeeping or budgets.

**Choose carefully:** Reported usage is not inferred provider billing and does not itself enforce external spending.

**Start with:** [usage.aggregate](../api/usage.aggregate.md), [usage.report](../api/usage.report.md), [usage.list](../api/usage.list.md).
