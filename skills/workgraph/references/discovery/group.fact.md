# fact

Generated from `workgraph discover --catalog`. Do not edit this file.

Facts are bounded named JSON values in explicit work scopes.

**Use when:** Agents need small editable shared context with revision guards and retained history.

**Choose carefully:** Use facts for structured values; resources retain larger text or binary content and immutable pins.

**Start with:** [fact.keys](../api/fact.keys.md), [fact.get](../api/fact.get.md), [fact.put](../api/fact.put.md).
