# template

Generated from `workgraph discover --catalog`. Do not edit this file.

Templates pin canonical graph specifications and instantiate deterministic ticket plans.

**Use when:** You need repeatable bounded work graphs with explicit placement and allocation or review policy.

**Choose carefully:** Instantiation creates planning state; the harness still dispatches and runs the workers.

**Start with:** [template.list](../api/template.list.md), [template.get](../api/template.get.md), [template.instantiate](../api/template.instantiate.md).
