# resource

Generated from `workgraph discover --catalog`. Do not edit this file.

Resources retain text or binary content with metadata revisions and immutable content versions.

**Use when:** Agents need to publish documents, logs or artifacts and retrieve exact evidence bytes.

**Choose carefully:** Metadata revisions guard edits; version and digest pin immutable content, while links attach it to work.

**Start with:** [resource.list](../api/resource.list.md), [resource.get](../api/resource.get.md), [resource.put_text](../api/resource.put_text.md), [resource.read](../api/resource.read.md).
