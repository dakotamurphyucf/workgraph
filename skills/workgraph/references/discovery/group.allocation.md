# allocation

Generated from `workgraph discover --catalog`. Do not edit this file.

Allocation policies restrict eligible runs and shared capacity before work starts.

**Use when:** Work requires named capabilities, permitted actors or a bounded shared pool.

**Choose carefully:** Allocation decides admission; readiness reads grant nothing and a reservation coordinates a specific resource.

**Start with:** [allocation.pools](../api/allocation.pools.md), [allocation.ticket_policies](../api/allocation.ticket_policies.md), [allocation.ticket_policy_put](../api/allocation.ticket_policy_put.md).
