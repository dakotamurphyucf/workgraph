# condition

Generated from `workgraph discover --catalog`. Do not edit this file.

Conditions record external prerequisites and explicit signals from the harness.

**Use when:** An outside system must report whether a work prerequisite currently holds.

**Choose carefully:** The daemon records caller signals; it never probes external systems or infers their state.

**Start with:** [condition.list](../api/condition.list.md), [condition.put](../api/condition.put.md), [condition.signal](../api/condition.signal.md).
