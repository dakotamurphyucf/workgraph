# activity

Generated from `workgraph discover --catalog`. Do not edit this file.

Planning activity records durable workspace changes and supports focused recovery summaries.

**Use when:** You need committed planning changes or a bounded digest of recorded work.

**Choose carefully:** Activity is the planning audit stream; history contains explicitly imported conversation events.

**Start with:** [activity.digest](../api/activity.digest.md), [activity.since](../api/activity.since.md), [activity.read](../api/activity.read.md).
