# upload

Generated from `workgraph discover --catalog`. Do not edit this file.

Upload staging accepts actor-owned opaque bytes before immutable resource publication.

**Use when:** A resource exceeds the small text method or contains binary bytes.

**Choose carefully:** Staging is ephemeral and unpublished; resource.finish_upload makes the content durable.

**Start with:** [upload.begin](../api/upload.begin.md), [upload.status](../api/upload.status.md), [upload.chunk](../api/upload.chunk.md).
