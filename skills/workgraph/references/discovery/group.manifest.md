# manifest

Generated from `workgraph discover --catalog`. Do not edit this file.

Manifests pin the exact named inputs and outputs used by an attempt.

**Use when:** Work must present reproducible evidence versions for validation or review.

**Choose carefully:** A manifest records pins; publishing one is not submission, review approval or acceptance.

**Start with:** [manifest.get](../api/manifest.get.md), [manifest.publish](../api/manifest.publish.md), [manifest.history](../api/manifest.history.md).
