# status

Generated from `workgraph discover --catalog`. Do not edit this file.

Statuses catalog ticket lifecycle categories and their planning metadata.

**Use when:** A workspace needs named Todo, active or terminal workflow statuses.

**Choose carefully:** Status assignment is planning metadata; claims and attempt state govern actual logical ownership.
