# ticket

Generated from `workgraph discover --catalog`. Do not edit this file.

Tickets are units of planned work with readiness, ownership, instructions and completion evidence.

**Use when:** You need to find ready work, claim it, report progress or complete it safely.

**Choose carefully:** Assignment is not ownership; claim tokens fence protected writes and the harness owns actual execution.

**Start with:** [ticket.list](../api/ticket.list.md), [ticket.context](../api/ticket.context.md), [ticket.readiness](../api/ticket.readiness.md), [ticket.start](../api/ticket.start.md).
