# workflow.ask_question

Generated from `workgraph discover --catalog`. Do not edit this file.

Create a pinned question, receive its exact answer and keep delivery acknowledgement separate.

**Use when:** A participant needs an answer from a designated resolver and must retain its provenance.

`workgraph help workflow.ask_question` · [Focused reference](../communication-evidence.md)

1. Save request.ask with explicit recipients, resolver_id and body; select a new topic or an existing thread with its actual expected_thread_revision.
2. Retain the returned request_id, request_revision and exact question reference; request.ask does not return a generic revision or status.
3. The designated resolver reads request.get, retains its current revision and saves request.resolve with that expected_revision and an optional nonblank answer body.
4. Read request.get or use the bounded local request.wait helper; inspect status.kind and the exact pinned answer, including a resolved request with answer:null.
5. Process inbox delivery separately and acknowledge only the selected handled notifications with inbox.ack; resolution never completes the linked ticket.
