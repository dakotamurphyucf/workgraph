# request

Generated from `workgraph discover --catalog`. Do not edit this file.

Requests track accountable questions and tasks with explicit recipients and resolvers.

**Use when:** A question or action needs delivery, responsibility, resolution and retained exact answers.

**Choose carefully:** Reading, inbox acknowledgement, request acknowledgement, acceptance and resolution are distinct.

**Start with:** [request.ask](../api/request.ask.md), [request.get](../api/request.get.md), [request.list](../api/request.list.md), [request.resolve](../api/request.resolve.md).
