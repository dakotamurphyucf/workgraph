# workflow.import_history

Generated from `workgraph discover --catalog`. Do not edit this file.

Convert selected visible transcript events, save exact bytes, and find them later under a fixed history capture.

**Use when:** You have a conversation or tool transcript to import, search and retrieve without loading the whole history.

`workgraph help workflow.import_history` · [Focused reference](../history.md)

1. Inspect the source format and select only user-visible messages and tool results. Never invent missing messages, import private reasoning, or treat recorded claims as verification.
2. Read references/history.md and the bundled scripts/history-adapter.py --help. The optional scripts/transcript-converter.py supports selected Claude JSONL records, not arbitrary role/content JSONL; inspect its --help and input requirements before use. These are Python scripts in the skill folder, not daemon API methods.
3. Create a session with session.create. Convert each event to a stable client_id, exact payload bytes and deliberately selected searchable_text; preserve source provenance. Append with session.append or the adapter, saving exact retry identities. Only durable acknowledgements permit discarding another copy.
4. Use history.search for selected text, retaining the returned history capture and event reference. Follow bounded continuation metadata before assuming the search was complete.
5. Use history.get and history.payload to retrieve the exact selected message or tool bytes at that capture. Check offsets, omitted content and payload hashes; planning workspace revisions are not history captures.
