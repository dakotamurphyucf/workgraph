# thread

Generated from `workgraph discover --catalog`. Do not edit this file.

Threads group retained discussion with exact message and attachment references.

**Use when:** A discussion needs durable replies, pins, attachments or accountable request context.

**Choose carefully:** Threads organize messages; requests track accountable work and inboxes track delivery.

**Start with:** [thread.list](../api/thread.list.md), [thread.get](../api/thread.get.md), [thread.reply](../api/thread.reply.md).
