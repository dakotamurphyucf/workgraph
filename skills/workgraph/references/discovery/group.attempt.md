# attempt

Generated from `workgraph discover --catalog`. Do not edit this file.

An attempt records one run's effort on a ticket under a particular claim.

**Use when:** You need to start, checkpoint or finish a distinct try at owned work.

**Choose carefully:** An attempt is retained execution bookkeeping; the harness launches the actual process.

**Start with:** [attempt.get](../api/attempt.get.md), [attempt.start](../api/attempt.start.md), [attempt.checkpoint](../api/attempt.checkpoint.md).
