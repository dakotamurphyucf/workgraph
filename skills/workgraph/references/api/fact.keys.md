# fact.keys

Generated from the CLI request and result definitions. Do not edit this file.

Discover scoped fact keys without loading their JSON values.

Tier: `core`. The result is `{data, meta}`; see [common envelopes and types](common.md).

| --- | --- | --- |
| `at_revision` | optional | string; pattern=&quot;^(0&#124;[1-9][0-9]*)(?![\\s\\S])&quot;; maximum decimal=&quot;4611686018427387903&quot; |
| `include_deleted` | optional | boolean |
| `limit` | optional | string; pattern=&quot;^(0&#124;[1-9][0-9]*)(?![\\s\\S])&quot;; maximum decimal=&quot;100&quot; |
| `max_bytes` | optional | string; pattern=&quot;^(0&#124;[1-9][0-9]*)(?![\\s\\S])&quot;; maximum decimal=&quot;1048576&quot; |
| `offset` | optional | string; pattern=&quot;^(0&#124;[1-9][0-9]*)(?![\\s\\S])&quot;; maximum decimal=&quot;4611686018427387903&quot; |
| `predicates` | optional | array; max items=8 |
| `prefix` | optional | string; max UTF-8 bytes=128 |
| `scope` | required | tagged alternatives; see complete schema; An explicit fact scope; values never inherit between scopes. |
| `workspace_id` | required | string; max UTF-8 bytes=96; Workspace identity. |

For preconditions and a small example, run `workgraph help fact.keys`. Use `--full` for the complete contracts below.

**Use when:** You need to find available shared context cheaply before selecting values.

**Capability:** [context](../discovery/capability.context.md).

**Related:** [fact.get](fact.get.md), [fact.put](fact.put.md).

**Effect:** read. Reads recorded state without changing it.
