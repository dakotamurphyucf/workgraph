# changes.read

Generated from the CLI request and result definitions. Do not edit this file.

Read complete captured commit metadata with exact prefix continuation.

Tier: `advanced`. The result is `{data, meta}`; see [common envelopes and types](common.md).

| Input | Presence | Type and constraints |
| --- | --- | --- |
| `actor_id` | optional | string; max UTF-8 bytes=96; Validated coordination identity. |
| `after` | optional | string; pattern=&quot;^(0&#124;[1-9][0-9]*)(?![\\s\\S])&quot;; maximum decimal=&quot;4611686018427387903&quot; |

| `limit` | optional | string; pattern=&quot;^(0&#124;[1-9][0-9]*)(?![\\s\\S])&quot;; maximum decimal=&quot;100&quot;; Validated cooperative coordination record. |

| `project_id` | optional | string; max UTF-8 bytes=96; Validated coordination identity. |
| `source` | optional | string; enum=[&quot;planning&quot;,&quot;history&quot;] |
| `target` | optional | tagged alternatives; see complete schema |
| `workspace_id` | required | string; max UTF-8 bytes=96; Validated coordination identity. |

For preconditions and a small example, run `workgraph help changes.read`. Use `--full` for the complete contracts below.

**Use when:** A consumer must follow planning or history commits without loading every payload.

**Capability:** [observation](../discovery/capability.observation.md).

**Related:** [changes.wait](changes.wait.md), [activity.since](activity.since.md), [history.read](history.read.md).

**Effect:** read. Reads recorded state without changing it.
