# run.get

Generated from the CLI request and result definitions. Do not edit this file.

Read one run&#x27;s immutable identity, reported lifecycle and entity revision.

Tier: `core`. The result is `{data, meta}`; see [common envelopes and types](common.md).

| Input | Presence | Type and constraints |
| --- | --- | --- |
| `head` | optional | string; max UTF-8 bytes=64; Lowercase SHA-256 journal head digest. &#124; null |
| `max_bytes` | optional | string; pattern=&quot;^(0&#124;[1-9][0-9]*)(?![\\s\\S])&quot;; maximum decimal=&quot;1048576&quot;; max_bytes must be 4096..1048576 |
| `target_run_id` | required | string; max UTF-8 bytes=96; Resolved opaque identity. |
| `workspace_id` | required | string; max UTF-8 bytes=96; Workspace identity. |

For preconditions and a small example, run `workgraph help run.get`. Use `--full` for the complete contracts below.

**Use when:** You need the exact invocation record before a guarded transition.

**Capability:** [coordination](../discovery/capability.coordination.md).

**Related:** [run.register](run.register.md), [run.observe](run.observe.md).

**Effect:** read. Reads recorded state without changing it.
