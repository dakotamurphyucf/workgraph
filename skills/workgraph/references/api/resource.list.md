# resource.list

Generated from the CLI request and result definitions. Do not edit this file.

List resource metadata under explicit scope, link and archive filters.

Tier: `core`. The result is `{data, meta}`; see [common envelopes and types](common.md).

| `include_archived` | optional | boolean |
| `limit` | optional | string; pattern=&quot;^(0&#124;[1-9][0-9]*)(?![\\s\\S])&quot;; maximum decimal=&quot;100&quot;; limit must be 1..100 |
| `max_bytes` | optional | string; pattern=&quot;^(0&#124;[1-9][0-9]*)(?![\\s\\S])&quot;; maximum decimal=&quot;1048576&quot;; max_bytes must be 4096..1048576 |
| `offset` | optional | string; pattern=&quot;^(0&#124;[1-9][0-9]*)(?![\\s\\S])&quot;; maximum decimal=&quot;4611686018427387903&quot; |
| `target` | optional | tagged alternatives; see complete schema; Resolved tagged resource-link filter. |
| `workspace_id` | required | string; max UTF-8 bytes=96; Workspace identity. |

For preconditions and a small example, run `workgraph help resource.list`. Use `--full` for the complete contracts below.

**Use when:** You need to find documents or artifacts without loading their bytes.

**Capability:** [context](../discovery/capability.context.md).

**Related:** [resource.get](resource.get.md), [resource.put_text](resource.put_text.md), [resource.read](resource.read.md).

**Effect:** read. Reads recorded state without changing it.
