# subscription.list

Generated from the CLI request and result definitions. Do not edit this file.

List retained notification subscriptions under explicit filters.

Tier: `advanced`. The result is `{data, meta}`; see [common envelopes and types](common.md).

| Input | Presence | Type and constraints |

| `limit` | optional | string; pattern=&quot;^(0&#124;[1-9][0-9]*)(?![\\s\\S])&quot;; maximum decimal=&quot;100&quot;; limit must be 1..100 |

| `offset` | optional | string; pattern=&quot;^(0&#124;[1-9][0-9]*)(?![\\s\\S])&quot;; maximum decimal=&quot;4611686018427387903&quot; |
| `recipient` | optional | object (requires kind, id); Actor recipient. &#124; object (requires kind, id); Run recipient. |
| `revision` | optional | string; pattern=&quot;^(0&#124;[1-9][0-9]*)(?![\\s\\S])&quot;; maximum decimal=&quot;4611686018427387903&quot; |
| `workspace_id` | required | string; max UTF-8 bytes=96; Workspace identity. |

For preconditions and a small example, run `workgraph help subscription.list`. Use `--full` for the complete contracts below.

**Use when:** You need to inspect which participants subscribed to scoped events.

**Capability:** [communication](../discovery/capability.communication.md).

**Related:** [subscription.get](subscription.get.md), [subscription.put](subscription.put.md).

**Effect:** read. Reads recorded state without changing it.
