# allocation.pool_put

Generated from the CLI request and result definitions. Do not edit this file.

Create or update a shared allocation pool&#x27;s guarded capacity limits.

Tier: `advanced`. The result is `{data, meta}`; see [common envelopes and types](common.md).

| Input | Presence | Type and constraints |
| --- | --- | --- |
| `actor_id` | required | string; max UTF-8 bytes=96; 1..96 ASCII letters, digits, underscores or hyphens |
| `expected_revision` | required | string; pattern=&quot;^(0&#124;[1-9][0-9]*)(?![\\s\\S])&quot;; maximum decimal=&quot;4611686018427387903&quot; |
| `limit` | required | string; pattern=&quot;^(0&#124;[1-9][0-9]*)(?![\\s\\S])&quot;; maximum decimal=&quot;10000&quot;; Pool limit in distinct allocated tickets (claim or live attempt), from 1 through 10000. | `mutation_id` | required | string; max UTF-8 bytes=96; 1..96 ASCII letters, digits, underscores or hyphens |
| `name` | required | string; max UTF-8 bytes=96; Nonblank UTF-8 text. |
| `run_id` | optional | string; max UTF-8 bytes=96; 1..96 ASCII letters, digits, underscores or hyphens |
| `workspace_id` | required | string; max UTF-8 bytes=96; 1..96 ASCII letters, digits, underscores or hyphens |

For preconditions and a small example, run `workgraph help allocation.pool_put`. Use `--full` for the complete contracts below.

**Use when:** You must limit how many admitted attempts can consume a shared capability or service.

**Capability:** [coordination](../discovery/capability.coordination.md).

**Related:** [allocation.pools](allocation.pools.md), [allocation.ticket_policies](allocation.ticket_policies.md), [allocation.ticket_policy_put](allocation.ticket_policy_put.md).

**Effect:** mutation. Changes durable state using a saved request identity, so an exact retry can recover its receipt.
