# decision.list

Generated from the CLI request and result definitions. Do not edit this file.

List recorded decisions matching explicit scope filters.

Tier: `advanced`. The result is `{data, meta}`; see [common envelopes and types](common.md).

| Input | Presence | Type and constraints |
| --- | --- | --- |
| `limit` | optional | string; pattern=&quot;^(0&#124;[1-9][0-9]*)(?![\\s\\S])&quot;; maximum decimal=&quot;100&quot;; Page limit from 1 through 100. |
| `max_bytes` | optional | string; pattern=&quot;^(0&#124;[1-9][0-9]*)(?![\\s\\S])&quot;; maximum decimal=&quot;1048576&quot; |
| `offset` | optional | string; pattern=&quot;^(0&#124;[1-9][0-9]*)(?![\\s\\S])&quot;; maximum decimal=&quot;4611686018427387903&quot; |
| `revision` | optional | string; pattern=&quot;^(0&#124;[1-9][0-9]*)(?![\\s\\S])&quot;; maximum decimal=&quot;4611686018427387903&quot; |
| `target` | optional | tagged alternatives; see complete schema |
| `workspace_id` | required | string; max UTF-8 bytes=96; Workspace identity. |

For preconditions and a small example, run `workgraph help decision.list`. Use `--full` for the complete contracts below.

**Use when:** You need to find durable choices relevant to the current work.

**Capability:** [verification](../discovery/capability.verification.md).

**Related:** [decision.get](decision.get.md), [decision.put](decision.put.md).

**Effect:** read. Reads recorded state without changing it.
