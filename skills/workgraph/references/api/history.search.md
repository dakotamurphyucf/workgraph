# history.search

Generated from the CLI request and result definitions. Do not edit this file.

Search retained imported conversation events with bounded results and source coverage.

Tier: `advanced`. The result is `{data, meta}`; see [common envelopes and types](common.md).

| Input | Presence | Type and constraints |
| --- | --- | --- |
| `after_event` | optional | object (requires session_id, sequence); Immutable committed session event reference. |
| `head` | optional | string; max UTF-8 bytes=64; Lowercase SHA-256 journal head digest. &#124; null |
| `kinds` | optional | array; max items=100 |
| `limit` | optional | string; pattern=&quot;^(0&#124;[1-9][0-9]*)(?![\\s\\S])&quot;; maximum decimal=&quot;100&quot;; limit requires 1..100 |
| `max_bytes` | optional | string; pattern=&quot;^(0&#124;[1-9][0-9]*)(?![\\s\\S])&quot;; maximum decimal=&quot;1048576&quot;; history budget requires 4KiB..1MiB |
| `session_id` | optional | string; max UTF-8 bytes=96; Resolved local identity. |
| `text` | required | string; max UTF-8 bytes=256; Nonempty UTF-8 lexical search text. |
| `workspace_id` | required | string; max UTF-8 bytes=96; Workspace identity. |

For preconditions and a small example, run `workgraph help history.search`. Use `--full` for the complete contracts below.

**Use when:** You need to find a prior visible message or tool event by text.

**Capability:** [context](../discovery/capability.context.md).

**Related:** [history.read](history.read.md), [history.get](history.get.md), [history.payload](history.payload.md).

**Effect:** read. Reads recorded state without changing it.
