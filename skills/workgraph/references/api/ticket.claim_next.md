# ticket.claim_next

Generated from the CLI request and result definitions. Do not edit this file.

Atomically select and claim eligible work; a standalone empty observation writes nothing.

Tier: `core`. The result is `{data, meta}`; see [common envelopes and types](common.md).

| Input | Presence | Type and constraints |
| --- | --- | --- |
| `actor_id` | required | string; max UTF-8 bytes=96; 1..96 ASCII letters, digits, underscores or hyphens |
| `attempt_id` | required | string; max UTF-8 bytes=97; Opaque ID, or $alias within transaction.apply; aliases resolve before command preparation. |
| `leaf_only` | optional | boolean; Exclude tickets with unfinished children; parents remain startable without this filter. |
| `lease_duration_ms` | optional | string; pattern=&quot;^(0&#124;[1-9][0-9]*)(?![\\s\\S])&quot;; maximum decimal=&quot;9223372036854775807&quot; |
| `mutation_id` | required | string; max UTF-8 bytes=96; 1..96 ASCII letters, digits, underscores or hyphens |
| `project_id` | optional | string; max UTF-8 bytes=97; Opaque ID, or $alias within transaction.apply; aliases resolve before command preparation. |
| `run_id` | optional | string; max UTF-8 bytes=96; 1..96 ASCII letters, digits, underscores or hyphens |
| `target_run_id` | required | string; max UTF-8 bytes=97; Opaque ID, or $alias within transaction.apply; aliases resolve before command preparation. |
| `workspace_id` | required | string; max UTF-8 bytes=96; 1..96 ASCII letters, digits, underscores or hyphens |

For preconditions and a small example, run `workgraph help ticket.claim_next`. Use `--full` for the complete contracts below.

**Use when:** A registered worker should take the next admitted task without a read-then-claim race.

**Capability:** [planning](../discovery/capability.planning.md).

**Related:** [ticket.ready](ticket.ready.md), [ticket.readiness](ticket.readiness.md), [ticket.start](ticket.start.md).

**Effect:** mutation. Changes durable state using a saved request identity, so an exact retry can recover its receipt.
