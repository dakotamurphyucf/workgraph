# registry.receipt

Generated from the CLI request and result definitions. Do not edit this file.

Read the registry-scoped durable receipt or pending intent for an exact mutation identity.

Tier: `advanced`. The result is `{data, meta}`; see [common envelopes and types](common.md).

| Input | Presence | Type and constraints |
| --- | --- | --- |
| `actor_id` | required | string; max UTF-8 bytes=96; Validated literal entity ID; registry administration is outside planning batches. |
| `mutation_id` | required | string; max UTF-8 bytes=96; Validated literal entity ID; registry administration is outside planning batches. |

For preconditions and a small example, run `workgraph help registry.receipt`. Use `--full` for the complete contracts below.

**Use when:** An administrative write may have committed and its saved request needs outcome recovery.

**Capability:** [administration](../discovery/capability.administration.md).

**Related:** [workspace.receipt](workspace.receipt.md), [retry](../cli-contract.md), [journal.inspect](../cli-contract.md).

**Effect:** read. Reads recorded state without changing it.
