# milestone.get

Generated from the CLI request and result definitions. Do not edit this file.

Read a milestone&#x27;s metadata, placement and current revision.

Tier: `advanced`. The result is `{data, meta}`; see [common envelopes and types](common.md).

| Input | Presence | Type and constraints |
| --- | --- | --- |
| `at_revision` | optional | string; pattern=&quot;^(0&#124;[1-9][0-9]*)(?![\\s\\S])&quot;; maximum decimal=&quot;4611686018427387903&quot; |
| `max_bytes` | optional | string; pattern=&quot;^(0&#124;[1-9][0-9]*)(?![\\s\\S])&quot;; maximum decimal=&quot;1048576&quot;; Canonical decimal within 4096..1048576. |
| `milestone_id` | required | string; max UTF-8 bytes=96; Resolved query identity. |
| `workspace_id` | required | string; max UTF-8 bytes=96; Workspace identity. |

For preconditions and a small example, run `workgraph help milestone.get`. Use `--full` for the complete contracts below.

**Use when:** You need the exact checkpoint record before updating its schedule or description.

**Capability:** [planning](../discovery/capability.planning.md).

**Related:** [milestone.list](milestone.list.md), [milestone.create](milestone.create.md), [milestone.schedule](milestone.schedule.md).

**Effect:** read. Reads recorded state without changing it.
