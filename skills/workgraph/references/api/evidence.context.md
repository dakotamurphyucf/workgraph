# evidence.context

Generated from the CLI request and result definitions. Do not edit this file.

Read the captured contracts, manifests, checks and policy evidence relevant to work.

Tier: `advanced`. The result is `{data, meta}`; see [common envelopes and types](common.md).

| Input | Presence | Type and constraints |
| --- | --- | --- |
| `max_bytes` | optional | string; pattern=&quot;^(0&#124;[1-9][0-9]*)(?![\\s\\S])&quot;; maximum decimal=&quot;1048576&quot; |
| `ticket_id` | required | string; max UTF-8 bytes=96; Validated ASCII identifier. |
| `workspace_id` | required | string; max UTF-8 bytes=96; Workspace identity. |

For preconditions and a small example, run `workgraph help evidence.context`. Use `--full` for the complete contracts below.

**Use when:** You need a joined evidence picture before inspecting or satisfying individual gates.

**Capability:** [verification](../discovery/capability.verification.md).

**Related:** [review.gate](review.gate.md), [acceptance.policy.effective](acceptance.policy.effective.md), [manifest.get](manifest.get.md).

**Effect:** read. Reads recorded state without changing it.
